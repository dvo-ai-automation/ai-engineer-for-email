# publiek/

Per build die als losse repo naar buiten gaat, één `README-template.md`. Bij het uitrollen
kopieer je het template naar de nieuwe repo als `README.md` en vul je het in.

Elk template heeft dezelfde vijf secties:

1. Wat het doet
2. Hoe je het draait
3. Wat de output is
4. Beperkingen
5. Wat er nog niet goed aan is

Alles tussen `<punthaken>` is een invulveld. Daar hoort iets in dat je gemeten hebt, niet iets
dat je aanneemt. Staat er nog een punthaak in, dan is de repo niet klaar om te publiceren.

Wat er niet in een template staat en er ook niet in hoort: een week, een maand, een traject, of
wat je van het bouwen hebt geleerd. Dat hoort in de werkbank, niet in de tooldocumentatie.
